tagline: "A research assistant for agronomy that scores how much to trust each answer, runs on self-hosted models, and works with no connection."

problem: "Field technicians and farmers need answers that are buried in dense technical manuals. A normal chatbot will sometimes invent an answer and state it with the same confidence it shows when it is right, which is the worst possible failure when someone is about to act on it in the field. The system answers questions from a fixed set of trusted manuals (a technique called retrieval-augmented generation, where the model reads from real documents instead of guessing). It was built inside a research project funded by FAPESP, the São Paulo state research foundation and one of the main public funders of science in Brazil, where I worked as a volunteer researcher."
constraints: "There was no budget for paid AI services, so the retrieval and answering pipeline had to run on free, self-hosted models. It had to keep working without reliable internet, since that is where it is used. And every answer needed a trust signal that a non-expert could read at a glance, not a yes or no flag meant for a developer."
approach: "Instead of a simple right or wrong flag, I built a confidence detector based on the semantic entropy method (Farquhar et al.). It asks the model the same question several times, groups the answers that mean the same thing, and measures how much they disagree, turning that disagreement into a single confidence score from 0 to 1. Answers also adapt to whether the reader is a beginner or a specialist, and the system is built on FastAPI, Qdrant and Ollama, which are open tools for serving the model and searching the documents. Later I replaced the agent's three guessed safety limits with measured ones: a sweep over 120 labeled questions set the topic filter at 96.7 percent true positives against 3.3 percent false positives, and twelve instrumented runs set the step and token ceilings."
alternatives: "A plain binary hallucination flag was the quick option, but it tells the user nothing about how unsure the system is, so a shaky answer looks identical to a solid one. The other option was to lean on a paid hosted model with its own guardrails. I rejected that because it broke both the self-hosting and offline requirements, and it would have tied a public research project to a recurring bill it cannot guarantee paying."
result: "A working system that ships a 0 to 1 confidence score with every answer, with embedding, retrieval and answering all running on local open-weight models and no paid dependency in that path. It is held to a production bar: 372 automated tests at 89.8 percent branch coverage of the core packages, strict type checking and linting in the build pipeline, fifteen written architecture decisions, and a packaged deployment with health checks and log rotation. The calibration evidence is committed as a fixture, so three tests fail the build if any safety default drifts away from what was measured. The full source, tests and evaluation pipeline are public in the repository."
evaluation: "The headline number measures the test suite, not the answers: 89.8 percent is branch coverage of the core packages, and no answer-quality score is published anywhere in this record, because the evaluation harness is built but has not been run end to end. What is measured against data is the calibration: 120 labeled questions for the topic filter, twelve instrumented runs for the step and token ceilings."
retrospective: "The confidence check costs more compute because it generates several answers per question, so accuracy and speed pull against each other. I deliberately put it behind a clean boundary so it can be split off and scaled on its own later, but for heavy traffic that trade-off would need a real rethink. The scoring step also defaults to a hosted verifier, and a fully local run means switching that provider explicitly. The evaluation harness is built but has not been run end to end, so the system has no published answer-quality numbers yet, and I have not claimed any."
